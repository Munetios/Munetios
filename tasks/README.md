## Munetios Accounts

Run the parent workspace server and open `/tasks/` to use the shared account menu. Sign in and unlock sync to sync tasks, categories, and task attachments with end-to-end encryption. Guest tasks remain available when signed out. To move them into an account, export your task backup as a guest, then sign in and import it.

The local IndexedDB data is stored separately for each account and for guest mode.
