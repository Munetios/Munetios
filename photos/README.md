# 📸 Munetios-Photos

A beautiful, fast, and secure photo viewing experience built for the Munetios ecosystem.  
Designed with **liquid-glass UI**, **Lexend fonts**, and a fully responsive layout.

---

## ⭐ Features
- Modern photo viewer  
- Albums, Favorites, Screenshots, Trash  
- Mobile footer navigation  
- Liquid Glass UI everywhere  
- Uses Munetios Beautiful CSS  
- Blob-based image security  
- Strict CSP  
- Offline-ready PWA  
- ZIP export powered by JSZip  

---

## 🪄 AI eraser
The editor's AI erase uses [MI-GAN](https://github.com/Picsart-AI-Research/MI-GAN) by Picsart AI Research (MIT license) with [onnxruntime-web](https://github.com/microsoft/onnxruntime) (MIT). It runs in the browser on WebGPU or WebAssembly. The model (about 28 MB) downloads once from Hugging Face after the user agrees, and stays in Cache Storage. Photos never leave the device.
