# About Munetios

## A privacy-focused productivity workspace

Munetios is a productivity platform built around privacy, accessibility, performance, and a consistent workspace. The current Documentation covers the released Calendar, Meet, and Tasks experiences.

## The Munetios Beta

Munetios is currently a Beta project. Features can change as reliability, accessibility, security, and regional support improve. Beta labels identify experiences that are still being completed or tested.

## Privacy and account data

Munetios limits data collection to information needed to provide, secure, and improve requested features. Account-backed apps document when information synchronizes, while guest experiences may keep supported preferences on the current device.

## Open-source project

The Munetios application project is open source. Account infrastructure, authentication systems, and account databases are separate proprietary services for security and privacy reasons.
