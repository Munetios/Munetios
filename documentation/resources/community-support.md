# Community and support

## Community links

Use the Documentation sidebar to visit Munetios on YouTube, X, TikTok, GitHub, or Discord. Community links open in the same tab. The Munetios Discord invitation is [discord.gg/sNgVNf9MdB](https://discord.gg/sNgVNf9MdB).

## Documentation assistant

Select **Chatbot** in the top bar to open the Documentation assistant. Its answers are grounded in the published Calendar, Meet, Tasks, and resource guides. Follow a cited documentation link when you need the complete instructions.

## Report a bug or request a feature

Use **Submit a feature request or bug report** in the sidebar. Describe what you expected, what happened, and the smallest safe set of steps that reproduces the issue. Remove passwords, recovery codes, payment information, and other sensitive content from screenshots.
