# Munetios changelog

## 0.1.0 Beta — August 23, 2026

- Launched the initial Munetios productivity workspace Beta.
- Added responsive, mobile-friendly application interfaces.
- Added privacy-focused Calendar, Meet, and Tasks experiences.
- Added internationalized interfaces and regional Beta availability controls.
- Added English Markdown Documentation with localized navigation and settings.
- Added the Documentation assistant with answers grounded in published guides.

## How changelog entries work

This page records notable user-facing additions, improvements, fixes, and availability changes. Small internal maintenance changes may not receive a separate entry.
