# Lists, categories, sharing, and teacher assignments

## Lists and categories

Create a list for a project or area of responsibility. Categories add another way to group related work. Rename or delete only items you own and review where existing tasks will appear after a change.

## Favorites, drafts, and status

Favorite frequently used tasks for quick access. Drafts keep unfinished task details separate from active work. Status views help distinguish work that is in progress, completed, archived, or deleted.

## Sharing

Share supported tasks only with people who need access. Review the recipient and permission before confirming. Removing access prevents future access but does not erase copies a recipient was already permitted to create.

## Teacher Assigned

Teachers can assign protected tasks to managed students. Students can view and check these tasks but cannot rename or edit the teacher-controlled task details. Teachers manage assignments from their education controls.
