# Get started with Munetios Tasks

![Munetios Tasks logo](/documentation/assets/tasks.svg)

Munetios Tasks helps you capture work, organize lists, track progress, and complete assigned items.

![Tasks overview on localhost](/documentation/screenshots/tasks-overview.png)

## Create a task

1. Select the create-task control.
2. Enter a clear title and optional details.
3. Choose a list, date, priority, category, or status when needed.
4. Save the task and confirm it appears in the expected view.

## Task views

Use the sidebar to open favorites, drafts, in progress, completed, archived, shared, trash, categories, and custom lists. Education student accounts can also see **Teacher Assigned**, a protected view for tasks created by a teacher.

## Complete and restore tasks

Check a task when it is complete. Move items to archive or trash only when they are no longer active. Restore recoverable tasks from the appropriate view before permanent removal.
