# Events, invitations, and calendars

## Event details and recurrence

Events can include a title, description, location, start and end time, recurrence, color, and notifications. Review the time zone before saving an event for people in different locations. Editing a recurring event lets you apply the change to the appropriate occurrence or series.

## Invite guests

Add guests using their email addresses, review the event details, and save to send the invitation. Guests can respond to the invitation from supported Munetios experiences. Only share information that every invited person should be able to see.

## Calendars and visibility

Create separate calendars for work, school, or personal schedules. Each calendar can have its own name, color, and visibility. Hiding a calendar removes its events from the current view without deleting them.

## Holidays, weather, and tasks

Calendar can show supported regional holidays and connected task information. Holiday availability follows the country selected in Calendar settings. Location-based features only run after the required permission is granted.
