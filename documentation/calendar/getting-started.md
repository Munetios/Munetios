# Get started with Munetios Calendar

![Munetios Calendar logo](/calendar.png)

Munetios Calendar keeps events, schedules, tasks, and invitations together in a privacy-first workspace.

![Calendar overview on localhost](/documentation/screenshots/calendar-overview.png)

## Open and navigate Calendar

Open **Calendar** from the app launcher. Use the sidebar to choose a calendar, the arrows to move through dates, and **Today** to return to the current date. Change between day, week, month, year, schedule, and custom views from the view control.

## Create your first event

1. Select **Create** or choose an empty time in the calendar.
2. Enter a title, date, start time, and end time.
3. Add optional details such as a location, description, recurrence, guests, or notifications.
4. Select **Save**. The event appears in the selected calendar.

## Search and keyboard access

Use Calendar search to find event titles and details. Use `Tab` and `Shift+Tab` to move between controls, `Enter` or `Space` to activate the focused control, and `Escape` to close an open menu or dialog.
