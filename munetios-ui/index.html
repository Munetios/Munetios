colorize

Color, date, and time pickers

Write a <button class="mu-picker-field" data-mu-picker="color|date|time|datetime"> with an optional data-value. The script opens the matching picker, shows the value (times use NM and AN), and fires change and mu-pick. Add data-input="id" to mirror the value into a hidden input. In code, call MunetiosUI.pickColor(), pickDate(), pickTime(), or pickDateTime() with { anchor, value, locale, labels, onPick }. The color picker is OmniWrite's: named swatches, a saturation and brightness area, a hue track, and a hex field.

YouTube player

Consent-gated nocookie embeds with YouTube's own controls and captions. The warning stays visible below the video. Application API requests use the same-origin Express proxy; playback connects to YouTube.

Existing dialog layouts can use mu-dialog-layer on the overlay and mu-dialog-surface on its direct panel. Call MunetiosUI.enhanceDialogLayer(overlay) to synchronize open state and allow clicks through the background.

web

Modal

Medium size and always in the same position. Open with data-mu-open; close with data-mu-close or Escape (clicking outside doesn't close it). You can keep clicking the page behind it, and opening it again stacks a duplicate in exactly the same spot. While any modal is open, danger actions on the page (like the Danger zone below) are locked.

translate

List picker

A searchable dialog for long lists such as languages and time zones. Call MunetiosUI.pickFromList({ title, icon, value, groups, searchLabel, emptyText, onPick }). Each item has a label, an optional sub line, and an optional trailing value. Arrow keys move through the list. Calendar uses it for the language and time zone pickers.

cloud_upload

Upload tray

A panel fixed to the bottom right while files upload. Call MunetiosUI.uploadTray({ title }), then tray.add({ name, icon }). Each item has progress(fraction, text), done(text), and fail(text, retry), and calls onCancel when someone cancels it. Photos uses it for cloud uploads.
